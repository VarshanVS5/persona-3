> Person 3 must not edit files outside these paths (other workstreams, shared contracts, root config, scripts, CI) without approval from that path's owner or the project owner. See `docs/PERMISSIONS.md`.

Project ATLAS is a **Windows desktop application**. You build the desktop app the user sees: the **Tauri 2 desktop shell** (`apps/desktop-ui/src-tauri/`, a native Windows window using WebView2) and the **React + TypeScript UI layer** rendered inside it (Vite is only the UI build tool). The UI talks only to the local Python backend on `127.0.0.1` (`docs/api-contract.md`); it never performs Windows automation itself and is not a security boundary (Master PRD 8.3).
